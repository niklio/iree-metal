# iree-metal 3.11.0.dev2026081801 — Developer Preview 5

This is the fifth experimental developer preview of the open iree-metal JAX
backend for Apple GPUs. It remains a prerelease without production support or
an API-stability commitment.

## Highlights

- The packaged plugin supports the verified JAX/JAXLIB range
  `>=0.10.2,<0.12` instead of pinning JAX 0.6.1. The offline bundle and the
  complete semantic/model/performance gates lock JAX/JAXLIB 0.11.1.
- PJRT device, client, buffer, executable, memory, and diagnostic metadata are
  implemented for the current JAX plugin API.
- Donation now carries result/input alias metadata through compilation and
  invalidates donated PJRT buffers after execution.
- Executable serialization/deserialization and stable fingerprints enable JAX
  persistent compilation caching and `jax.export` round trips.
- Metal device allocations can be exported and imported for same-device DLPack
  round trips while retaining the backing allocation for the capsule lifetime.
- Stream timepoints derived by control-flow barriers are preserved, fixing the
  incorrect `cond` result found by the compatibility verifier.
- The `preview-20260818` profile carries forward the Preview 4 optimizations
  that remain correct under the current JAX lowering and requires no tuning
  environment variables. The exact-graph ViT raw-pad matmul and dead-row-fill
  rewrites remain disabled: sustained JAX 0.11.1 verification found that each
  could silently corrupt unsampled ViT backward gradients. Three independently
  verified attention/QKV fill eliminations remain enabled.
- Small-output scatters and fully static BF16 embedding gradients with at most
  4,096 batch elements use a 32-wide window. Larger or dynamic BF16 batches and
  large-output F32 scatters retain resource-derived tiling. This recovers model
  throughput without repeating the 540 KiB threadgroup-memory request that the
  verifier found in full-vocabulary F32 decoder training.

## Validation contract

Publication is gated on one immutable compiler/plugin wheel pair. The release
must pass:

- all 17 clean-wheel JAX/PJRT probes on JAX/JAXLIB 0.11.1 and 0.11.0, plus the
  recorded current nightly lane;
- 233 BF16/F32 semantic cases;
- nine decoder-training operator/resource cases;
- ten deterministic BF16 Hugging Face model-family forward-and-backward
  workloads; and
- twelve paired decoder-training performance workloads across three model
  families and four training phases.

Every correctness, compilation, resource, determinism, and stability check must
pass. The Hugging Face board additionally requires a geometric-mean throughput
ratio strictly above 1.00x versus live jax-metal. Decoder-training performance
requires an overall ratio of at least 0.95x, every phase at least 0.90x, every
workload at least 0.80x, and robust worker CV no greater than 10%.

The attached verifier evidence is authoritative for the exact release wheels.
The comparison is limited to the disclosed Apple M4, CPython 3.12, recorded
macOS version, deterministic inputs, model shapes, synchronization, and
aggregation method. It is not a claim of universal JAX, model, workload, or
Apple GPU parity.

## Supported configuration

- Apple M4
- macOS and Xcode versions recorded in the attached manifest
- CPython 3.12
- JAX/JAXLIB `>=0.10.2,<0.12`, limited to the exact pairs in the compatibility
  evidence
- Matching compiler and plugin wheels from this release

The compatibility bridge uses plugin-local, version-tested JAX hooks where a
public backend-capability API is unavailable. A new JAX release is unsupported
until it passes the compatibility matrix even if the dependency resolver admits
it. The `macosx_13_0_arm64` wheel tag is a deployment target, not evidence that
the preview was tested across every macOS 13+ configuration or Apple GPU.

## Numeric and compatibility limitations

The optimized profile's causal-attention bounds assume finite model inputs and
can change NaN/Inf propagation through masked arithmetic. Use
`IREE_METAL_PROFILE=baseline` for non-finite diagnostics. Dynamic shapes,
multiple devices, distributed execution, broad upstream JAX test-suite
compatibility, Python versions other than 3.12, and non-M4 Apple GPUs remain
outside this preview's claim.

## Install

After publication, install the platform-constrained metapackage in a fresh
Python 3.12 environment:

```bash
python -m pip install iree-metal==3.11.0.dev2026081801
```

For an offline or fully auditable installation, use the attached
`iree-metal-preview-3.11.0.dev2026081801-macos-arm64.tar.gz` bundle and verify
its `.sha256` sidecar before extraction.
